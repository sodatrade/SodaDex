# 矿机业务与收费基线核对（2026-10-19）

本次是经用户确认的文案与文档修订，不是生产收费启用。两套流程保持独立：

- 募资分红：FAB 计价发行项目币，交易税注入共享矿场，采购矿机并向合格持有人分红。不是出售某台矿机的碎片。
- 矿机碎片：先存入合格 NFT，按基础算力发行整个金库的份额，支持交易、分红和足额销毁赎回。没有募资成功／失败阶段。

依据为 2026-10-16 的《矿机分红金库 V1.5》§0/§6 和《矿机碎片化交易 V1.2》§3/§5。本机源文档位于 Downloads 中同日期的 ignix_miner-vault-prd.md 和 ignix_miner-fragmentation-prd.md。原文不随此提交复制。

## PRD 基线与测试实现的区别

| 事项 | PRD | 当前可核查证据 / 后续工作 |
| --- | --- | --- |
| 矿机碎片份额 | 开放式共同金库；首次每点权重 1,000 份 | FabFragmentVault 的存取按权重和现有供应计算；不新增单矿机募资 |
| 碎片交易费 | 输入额 0.5%，平台 30% / LP 70% | 当前测试配置沿用；不是新待定费率 |
| 碎片存取 | 无产品手续费 | 保持免费，赎回销毁本金份额不算手续费 |
| 募资买卖税 | 双侧 1%–10%，创作者选择，默认 1% | 测试采用 1%；不改生产参数 |
| 税款分配 | 平台占税款 1%–10%（默认 10%）；创作者占余款 0%–50%（默认 10%） | 测试选择平台 1%、创作者 0%；生产实例参数仍需确认 |
| 募资产出费 / 碎片服务费 | 默认 5% / 固定 10% | 测试配置均为 0；当前收益支付没有完整的生产非零扣费链路，不宣称已完成 |
| 碎片每日自动分红 | 约 1 USD 门槛，Gas 从分红扣 | MiningRewardShares 有 claimFor，但支付全部可领余额；当前 Planner 处理税款同步、注资、转换和采购，不是每日持有人分发器。价格换算、实际 Gas 归属、扣费上限及失败账本尚须补充并验证 |
| 募资调费 | 产出费默认可调 | 谁可调、最高值、存量项目何时生效尚未定；不自行增加 setter |
| 异常矿机与烧币边界 | 原 PRD 有未决或冲突 | 已批准的测试补充规则继续有效；不能仅凭本次文案检查声称生产全场景验收通过 |

以上是源码与已有配置核对，不是本次链上验收。仍需生产功能实现及新一轮端到端验证；本次没有部署、签名或资金操作。
