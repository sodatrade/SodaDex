# 普通代币池：哪些能用，哪些还缺

SodaDEX 普通池目前接入 V3 和无 Hook 的 V4。V2 尚未接入普通池交易。这里的“矿机专用池第三版”是专用合约的修订版本，不是 Uniswap V3。

| 功能 | V2 | V3 | V4 |
| --- | --- | --- | --- |
| 新建池并首次添加 | 未接入 | 已实现 | 已实现，仅无 Hook 池 |
| 追加流动性 | 未接入 | 已实现 | 已实现 |
| 部分／全部移除 | 未接入 | 已实现，减仓时一起取回资产 | 已实现，减仓时一起取回资产 |
| 单独领取池内待领取资产 | 未接入 | 已实现 | 已实现 |
| 双向兑换 | 未接入 | 已实现，精确输入／精确输出 | 已实现，精确输入／精确输出 |
| 用户持仓形式 | 尚无普通池 LP 适配 | 仓位 NFT | 仓位 NFT |

## 怎样操作

- 建池：Pool → 创建池 / 新仓位 → 选择 V3 或 V4 → 选择币种或按地址导入 → 配置费率 → 未初始化的池设置初始价格 → 填入数量、预览并确认。
- 向已有池加钱：在池列表点击“管理流动性”，查看池详情后点击“添加流动性”。
- 追加或移除：Pool → 我的仓位 → 选择自己的仓位；可以增加、按比例减少、全部移出或领取待领取资产。未列出的 NFT 可按协议和 Token ID 查询。
- 兑换：Swap 选择支付与接收币种；默认自动比较本方直接单池的报价，也可在设置中指定 V3 或 V4。没有合适池时明确显示不能报价，不会自动转去官方池交易。

普通池沿用各协议本身的费率。矿机 OKB/sFAB 专用池才使用“总计 0.5%，平台 30%、LP 70%”的独立规则。

## 仍然缺什么

1. **V2 普通池的全套适配。** 还缺建池、LP ERC-20 仓位、授权、报价、Swap、Worker 校验及验收；旧矿机依赖中的 TEST V2 Router 不代表普通池已经支持 V2。
2. **带 Hook 或动态费率的 V4。** 当前只接受零地址 Hook。
3. **多跳和官方池交易。** 当前兑换只使用已发现的 SodaDEX 自有直接单池；官方池保持只读。按地址导入代币，也不保证该币存在可交易的池。
4. **V4 仓位的服务端持有人索引。** 现有客户端仍读取 Transfer 历史后核对真实 owner。V3/V4 已拆成独立查询，一个协议读取慢不会挡住另一个；按 Token ID 查询仍可用。
5. **其他访客的新池目录同步窗口。** 当前建池会话先使用成功交易后重新核验的池，因此可立即继续报价；其他访客及刷新后的会话仍等后台追到新区块后发现池。读取失败不改变已确认的交易结果。
6. **特殊行为代币。** 可导入标准 ERC-20，不代表所有转账税、重基或非标准返回值代币均受支持。

“我的”当前展示 OKB、sFAB 与矿机专用池 LP 本金；普通 V3/V4 的仓位仍在 Pool → 我的仓位。矿机存取、金库、国库及收益领取由 IGNIX 承接。

生产合约、生产国库与生产 Locker 均未调整。
