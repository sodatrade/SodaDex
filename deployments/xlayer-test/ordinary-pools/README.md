## 怎样操作

- 建池：Pool → 创建池 / 新仓位 → 选择协议 → 选择币种或按地址导入。V2 固定 0.3% 费率，首次投入的两币比例决定开盘价；V3/V4 需选择费率，未初始化的池需设置初始价格。随后填入数量、预览并确认。
- 向已有池加钱：在池列表点击“管理流动性”，查看池详情后点击“添加流动性”。
- 追加或移除：Pool → 我的仓位 → 选择自己的仓位；可以增加、按比例减少、全部移出或领取待领取资产。未列出的 NFT 可按协议和 Token ID 查询。
- 兑换：Swap 选择支付与接收币种；默认自动比较本方直接单池的报价，也可在设置中指定 V2、V3 或 V4。没有合适池时明确显示不能报价，不会自动转去官方池交易。

普通池沿用各协议本身的费率。当前 V2 为 0.3%，Factory 的 feeTo 为零，手续费保留在 LP 储备里；不会按专用池的 30%／70% 另外拆账。矿机 OKB/sFAB 专用池才使用“总计 0.5%，平台 30%、LP 70%”的独立规则。

## 仍然缺什么

1. **普通池多币种覆盖边界。** V2 公链验收覆盖 TEST-FAB／TEST-V2 和 TEST-FAB／OKB；V3／V4 覆盖 TEST-FAB／OKB。这不等于验证了每种任意导入代币。
2. **带 Hook 或动态费率的 V4。** 当前只接受零地址 Hook。
3. **多跳和官方池交易。** 当前兑换只使用已发现的 SodaDEX 自有直接单池；官方池保持只读。按地址导入代币，也不保证该币存在可交易的池。
4. **仓位的服务端索引与分页。** V3 目前逐个读取钱包持有的 NFT，V4 读取转移历史后再核对持有人；页面每页最多 10 条，但持仓很多时首次读取仍会变慢。V3/V4 已拆成独立查询，一个协议读取慢不会挡住另一个；按 Token ID 查询仍可用。
5. **其他访客的新池目录同步窗口。** 当前建池会话先使用成功交易后重新核验的池，因此可立即继续报价；其他访客及刷新后的会话仍等后台追到新区块后发现池。读取失败不改变已确认的交易结果。
6. **特殊行为代币。** 可导入标准 ERC-20，不代表所有转账税、重基或非标准返回值代币均受支持。旧 TEST-FAB196 买卖税为 1%，已从普通 V2 标准币通道排除；这项排除不是对所有新导入代币的安全认证。

“我的”当前展示 OKB、sFAB 与矿机专用池 LP 本金；普通 V2/V3/V4 的仓位仍在 Pool → 我的仓位。矿机存取、金库、国库及收益领取由 IGNIX 承接。

生产合约、生产国库与生产 Locker 均未调整。
